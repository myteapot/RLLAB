# Scratch

This directory is the non-formal runtime surface for the project.

- `checkpoints/` — active experiment checkpoints
- `reports/` — active LLM analysis reports
- `rewards/` — active generated reward code
- `config_snapshots/` — active config snapshots
- `logs/` — active runtime logs
- `videos/` — rendered evaluation videos
- `legacy/pre-ckp/` — preserved artifacts from before the CKP retrofit

Nothing in `scratch/` is formal project truth unless it is promoted into `spec/` or `src/`.
